# שעון נוכחות

אפליקציית ווב (PWA) לדיווח נוכחות לפי מיקום עבור הישיבה: אברכים, תלמידים, עובדים ורבנים.

## מה יש כאן

| מסך | כתובת | מי |
|---|---|---|
| כניסה והרשמה בקוד מהמייל | `/login` | כולם |
| השלמת פרטים (שם, ת.ז, תפקיד) | `/onboarding` | משתמש חדש, פעם אחת |
| דיווח כניסה ויציאה לפי GPS | `/` | כולם |
| ניהול: יומן, סיכום שעות, משתמשים, הגדרות, ייצוא CSV | `/admin` | מנהלים |

- **אין סיסמאות.** כניסה עם קוד בן 6 ספרות שנשלח למייל.
- **חיבור קבוע.** החיבור נשמר בעוגיות לטווח ארוך ומתחדש ברקע. המשתמש מתנתק רק אם הוא לוחץ "התנתקות".
- **בדיקת המרחק נעשית בשרת** (`report_attendance` ב-PostgreSQL עם PostGIS). הטלפון שולח רק את המיקום, והשרת מחליט.
- **מנהלים:** מי שנרשם עם מייל שמופיע בטבלה `admin_emails` מקבל הרשאת ניהול אוטומטית.

## מבנה

```
app/                 מסכים (Next.js App Router)
components/          רכיבים משותפים
lib/                 חיבור ל-Supabase, תוויות, בדיקת ת.ז
middleware.ts        חידוש חיבור והפניה למסך כניסה
supabase/migrations/ כל הגדרות בסיס הנתונים, לפי הסדר
public/              אייקונים ו-manifest של ה-PWA
```

## הרצה מקומית

```bash
npm install
npm run dev
```

כתובת Supabase והמפתח הציבורי נמצאים ב-`lib/config.ts`. אפשר לדרוס אותם במשתני סביבה, ראו `.env.example`.

## פריסה ל-Vercel

1. ב-vercel.com: **Add New Project** ← לבחור את המאגר הזה.
2. Vercel מזהה Next.js לבד. לא צריך להגדיר כלום, ללחוץ **Deploy**.
3. כל דחיפה לענף `main` עולה לאוויר אוטומטית.

## הגדרות שנעשות בלוח של Supabase

1. **תבנית המייל:** Authentication ← Emails ← Magic Link. להחליף את הגוף בקוד:
   ```html
   <h2>קוד הכניסה שלך לשעון הנוכחות</h2>
   <p style="font-size:28px;letter-spacing:6px"><b>{{ .Token }}</b></p>
   <p>הקוד תקף לזמן קצר. אם לא ביקשת אותו, אפשר להתעלם מהמייל.</p>
   ```
2. **שרת מייל (SMTP):** שרת המייל המובנה של Supabase שולח רק לחברי הצוות של הפרויקט ובכמות מוגבלת. לפני שמזמינים משתמשים צריך לחבר שרת מייל, למשל Resend: Authentication ← Emails ← SMTP Settings.
3. **Site URL:** Authentication ← URL Configuration. להזין את כתובת האתר ב-Vercel.
